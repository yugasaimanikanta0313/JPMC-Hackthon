# Demo guide

1. Start MongoDB and all three services.
2. Sign in as the environment-bootstrapped administrator.
3. Create a project and invite student, mentor, and client accounts.
4. Add a requirement and document; ingest it into project-scoped knowledge.
5. Ask a supported question and inspect cited evidence.
6. Ask an unsupported question; open the generated mentor queue item.
7. Resolve it as a mentor, mark verified and reusable, then ask a similar question.
8. Show portfolio health, self-resolution, escalation, and provider usage metrics.
